# 斬字 Zanji · Kanji Duel

เกมแฟลชการ์ดคำศัพท์ญี่ปุ่น พร้อมแดชบอร์ดทบทวนแบบเว้นระยะ เช็คอินรายวัน และเสียงอ่านจริง

- เปิดเล่น: ผ่าน GitHub Pages ของ repo นี้
- ซิงก์ข้ามเครื่อง: ใส่ค่า Firebase ใน `firebase-config.js` (ถ้าเว้นเป็น `null` จะเก็บในเครื่องอย่างเดียว)
- กฎ Firestore อยู่ใน `firestore.rules`

เสียงและข้อมูลคำของชุด Kaishi 1.5k มาจากเด็ค [Kaishi](https://github.com/donkuri/Kaishi) ใช้เพื่อการเรียนส่วนตัว
