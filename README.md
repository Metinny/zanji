# 斬字 Zanji · Kanji Duel

## ▶ [กดตรงนี้เพื่อเล่นเกม](https://metinny.github.io/zanji/)

**https://metinny.github.io/zanji/**

---

เกมแฟลชการ์ดคำศัพท์ญี่ปุ่น ตอบถูกฟันคันจิขาด ตอบผิดโดนฟันกลับ พร้อมแดชบอร์ดทบทวนแบบเว้นระยะ เช็คอินรายวัน และเสียงอ่านจริง

**วิธีเล่น**
1. กดลิงก์ด้านบน
2. เลือกชุดคำ: N5 พื้นฐาน หรือ Kaishi 1.5k
3. กด "เรียนคำใหม่" แล้วเลือกความหมายที่ถูก (กดปุ่ม 1–4 ได้)
4. วันต่อไป กด "ทบทวน" คำที่ถึงกำหนดก่อน

บนมือถือ: เปิดลิงก์ แล้วเลือก "Add to Home Screen" จากเมนูเบราว์เซอร์ จะได้ไอคอนไว้กดเล่นเหมือนแอป
